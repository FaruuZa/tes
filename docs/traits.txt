=== CLASH ROYALE CLONE - TRAITS & TAGS REFERENCE ===

[ LOGIC TAGS ]
Digunakan dalam array `tags: [...]` di data.js untuk menentukan perilaku unit.

--- Tipe Unit ---
ground          : Unit berjalan di darat.
air             : Unit terbang (melewati sungai, hanya diserang air-target).
single          : Serangan target tunggal.
area            : Serangan area (Splash Damage).
building-hunter : Hanya menyerang bangunan (Giant, Hog Rider).
heavy           : Unit berat, tidak mudah didorong, prioritas push (PEKKA, Golem).
fast            : Unit cepat, digunakan bot untuk bridge spam (Hog, Bandit).
spawner         : Unit yang memunculkan unit lain (Witch).
healer          : Unit yang menyembuhkan teman (Battle Healer).
shielded        : Memiliki shield yang harus hancur sebelum HP utama berkurang.
charge          : Melakukan charge damage ganda setelah berlari (Prince).
kamikaze        : Mati saat menyerang (Spirits, Wall Breakers).
siege           : Bangunan/Unit penyerang jarak jauh (X-Bow, Princess, Mortar).

--- Target ---
air-target      : Bisa menyerang unit udara.
ground-only     : Hanya bisa menyerang darat (biasanya untuk bangunan/spell).

--- Efek Serangan ---
stun-effect     : Serangan memberikan efek Stun/Zap (E-Wiz).
slow-effect     : Serangan memberikan efek Slow (Ice Wiz, Yeti).
freeze          : Efek membekukan total (Ice Spirit).
ramp-damage     : Damage meningkat seiring waktu (Inferno Tower/Dragon).
log             : Efek knockback log (The Log).

[ STATS PROPERTIES ]
Digunakan dalam objek `stats: { ... }`

hp              : Hitpoints (Nyawa)
dmg             : Damage per hit
hitSpeed        : Kecepatan serangan (detik, makin kecil makin cepat)
speed           : Kecepatan gerak (0.5 lambat - 2.0 cepat)
range           : Jarak serangan (grid). 0 = Melee.
sightRange      : Jarak pandang untuk mengejar musuh.
count           : Jumlah unit yang muncul saat spawn.
deployTime      : Waktu tunggu sebelum unit bisa bergerak/serang.
loadTime        : Waktu reload khusus (Sparky/Sniper).
splashRadius    : Radius area damage.
stunDuration    : Durasi efek stun (detik).
slowDuration    : Durasi efek slow (detik).
slowAmount      : Persentase slow (0.3 = 30%).
chargeDmg       : Damage saat charge (Prince).
projectile      : Tipe peluru ('rolling', 'rolling_log', 'boomerang', 'normal').
projSpeed       : Kecepatan peluru.
maxRange        : Jarak maksimal peluru (khusus boomerang/rolling).
multiTarget     : Jumlah target sekaligus (E-Wiz = 2).

--- Special Effects Objects ---
deathEffect: {
